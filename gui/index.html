Jain's Fairness Index Formulation

Measures how equally blackout hours \(x_i\) are divided among non-critical neighborhoods:

J(x₁, ..., xₙ) = (Σ xᵢ)² / [ n · Σ (xᵢ)² ]
  • J = 1.0 (100%): Absolute equity (every neighborhood receives identical hours).
  • J → 1/n: Severe unfairness (one area absorbs all blackouts).
  • Current FairShed Score: 0.988 (98.8% Fair) with standard deviation of only 0.31 hours.
